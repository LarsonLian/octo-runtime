# 局部争议

- **API还是CLI**：固定历史准备直接复用TypeScript消息API；模型工具循环的额外业务动作仍走octo-cli。不是新增业务执行器或交付补偿钩子。
- **2条还是固定15条**：小缺口按序号跨度，最多15条；未知基线和大缺口只取最近15条。不是每次固定重拉15条。
- **是否追完整**：不追more、不翻页；代码过滤、去重、截条数及1500码点，10秒、一次HTTP、禁用429重试。更早结论不在窗口时如实说明。
- **独立问题是否查**：只判断位置缺口，不做关键词或模型分类。无缺口不查，有缺口固定准备，即使当前问题无需历史。
- **是否已读**：API成功、正文进入最终快照、模型实际阅读是三个事实；只记录前两者，不造跨进程已读watermark。
- **失败是否阻断**：辅助历史失败继续当前任务并标状态；取消必须向上传递，正文省略保留待补边界，不换身份或启动CLI补救。
