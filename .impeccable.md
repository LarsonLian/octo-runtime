## Design Context

### Users

Engineers operating or debugging an Octo Harness daemon on their own machine. They need to distinguish event sources, isolate one AgentRun, inspect durable logs, and verify runtime and memory state without interrupting execution.

### Brand Personality

Quiet, precise, utilitarian. The interface should convey control and operational confidence, not novelty or promotion.

### Aesthetic Direction

A dense local diagnostics console with restrained contrast, clear source color coding, stable layout, and strong scanability. It should feel like a purpose-built engineering instrument. Avoid marketing composition, decorative cards, gradients, glow effects, and oversized typography.

### Design Principles

- Keep the event timeline primary and make source, type, and payload easy to compare.
- Use compact controls and stable dimensions so live updates never shift the surrounding layout.
- Treat runtime, durable logs, and memory as peer diagnostic views in one surface.
- Preserve readable contrast and keyboard-visible controls without decorative motion.
- Never expose the inspector beyond loopback or display credentials in the interface.
